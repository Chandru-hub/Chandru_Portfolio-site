# Chandrasekar S - Portfolio

Full-stack developer portfolio built with React, TypeScript, Redux, and Framer Motion.

## Quick Start

```bash
npm install
npm start
```

## Features

- ✅ TypeScript
- ✅ React 18
- ✅ Redux Toolkit
- ✅ Framer Motion
- ✅ Dark/Light mode
- ✅ Responsive
- ✅ SOLID principles
